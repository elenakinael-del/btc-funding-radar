# Bitcoin Funding Rate Term Structure Radar 🔬

An institutional-grade quantitative trading dashboard built to map the term structure of synthetic yields generated by perpetual swap funding rates across multiple execution venues. 

### Key Features:
* **Dynamic 3D Topography Surface:** Visualizes 8-hour, 1-day, 3-day, and 7-day projected funding tenors to identify curve deformations (Contango vs. Backwardation).
* **Live Market Synced Candlesticks:** Integrates real-time spot index data from public endpoints.
* **Automated Strategy Signal Layer:** Detects cross-venue basis dislocations to flag actionable delta-neutral arbitrage execution parameters.
